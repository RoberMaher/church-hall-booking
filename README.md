# احجز سمارت مش هارد ✨ — حجز قاعات الكنيسة

🔗 **جرّبه لايف:** https://robermaher.github.io/church-hall-booking/

منظومة الحجز الإلكتروني الذكي لقاعات كنيسة العذراء ويوحنا الحبيب — جناكليس، الإسكندرية.

## الدخول

شاشة الدخول بالكود — كودك يحدد وجهتك، ومحدش بيدخل من غير كود:

| الكود | بيفتح |
|---|---|
| `SEC-ADMIN-01` | لوحة تحكم السكرتارية (إضافة القاعات والحسابات والأكواد، الإشعارات، الجدول الأسبوعي، إلغاء الحجوزات) |
| `SRV-BOYS-PRI` | حجز الخدمات (القاعات، الحجز بالساعة، التذكرة) |

## للسكرتارية

1. ادخل بكود السكرتارية.
2. ضيف القاعات (اسم + سعة + دور) — الموقع بيبدأ من الصفر.
3. ضيف أكواد الخدمات مع اسم أمين الخدمة.
4. تابع الإشعارات واعتمد/ارفض، واتحكم في الجدول الأسبوعي (7 أيام + حظر ساعات من-إلى) وألغِ أي حجز.

## ملحوظة

البيانات محفوظة محليًا في متصفح كل جهاز (localStorage) — القاعات والحجوزات اللي بتضيفها عندك مش بتظهر على أجهزة تانية.
